# AI飞花令 (feihualing-game)
一款基于AI的诗词飞花令对战工具，让每个人都能轻松体验传统诗词文化的魅力。
## 项目简介
用AI陪你玩诗词飞花令，自动对诗、判词、给出经典诗句，让诗词爱好者轻松感受传统文化乐趣。
## 项目类型
AI应用 / 人文VibeCoding
## 项目版本
1.0.0
## 项目功能
- 随机生成飞花令关键字
- AI自动匹配含该字的经典古诗词
- 支持双人轮流对诗
- 诗句合规性与重复判断
- 显示诗句出处、作者、译文
- 简洁友好的交互界面
## 设计思路
本项目希望用AI技术降低传统文化体验门槛，让更多人尤其是青少年，在轻松有趣的飞花令游戏中亲近古诗词，感受中华诗词之美，实现传统文化在数字时代的传承与创新。
#用AI重新看见人
## 使用方式
1. 输入或随机抽取一个汉字
2. AI 自动给出符合规则的诗词句子
3. 双方轮流作答，系统判断是否合规
4. 可查看诗句背景知识，边玩边学
## 技术栈
- 大语言模型
- 古诗词知识库
- 简单前端交互界面
